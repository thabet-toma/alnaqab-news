# موقع النقب الإخباري — البوابة الإخبارية والراديو المباشر

بوابة إخبارية عربية متكاملة واحترافية متخصصة في أخبار وقضايا النقب والداخل الفلسطيني، مع مشغل راديو تفاعلي مدمج وصفحة راديو مستقلة ذات طابع ليلي صحراوي فاخر.

---

## 🌟 الميزات الرئيسية

- **📰 الواجهة الإخبارية الفاخرة:**
  - هيدر حديث مع شريط علوي ومؤشر بث مباشر، التاريخ والوقت بالعربية، وأيقونات تواصل.
  - شريط أخبار عاجلة متحرك وذكي (Marquee Ticker).
  - سلايدر الأخبار المميزة في الصفحة الرئيسية (Hero Featured Slider).
  - شبكة عرض المقالات والأخبار بتصميم 16:9 وتأثيرات Hover حديثة.
  - قسم خاص بمقالات الرأي والتحليلات مع بطاقات الكتّاب.
  - دعم كامل لترقيم الصفحات وتصنيف الأخبار والبحث المتقدم.

- **📻 نظام الراديو المباشر (Radio Integration):**
  - **ودجت جانبي تفاعلي (Mini Player):** يحتوي على مؤشر صوتي متحرك (Audio Equalizer) وزر تشغيل فوري.
  - **صفحة راديو متكاملة (`radio.php`):** ذات طابع صحراوي ليلي، نجوم متلألئة، كثبان رملية، شريط رسائل، مؤقت نوم، وإدارة إعلانات صوتية/مرئية خاصة بالراديو.

- **🛡️ لوحة الإدارة والتحكم (Admin Dashboard):**
  - نظام تسجيل دخول آمن ومحمي ضد هجمات CSRF و XSS.
  - إدارة كاملة للمقالات والأخبار (إضافة، تعديل، حذف، تحديد الأخبار العاجلة والمميزة).
  - رفع ومعالجة الصور بشكل آمن.
  - إدارة الأقسام والتصنيفات.
  - إدارة الإعلانات بمختلف مواضعها (الهيدر، الشريط الجانبي، بين المقالات).
  - إعدادات البث المباشر للراديو وحفظها بصيغة JSON.
  - إعدادات الموقع العامة وحسابات التواصل.

- **🚀 سهولة التثبيت والنشر:**
  - سكريبت تثبيت آلي (`install.php`) لإنشاء الجداول وحساب المدير الأول بضغطة زر.
  - جاهز للنشر المباشر على استضافات **Hostinger** و **cPanel** و **LiteSpeed**.

---

## 🛠️ المتطلبات التقنية

- **PHP:** الإصدار 8.0 فما فوق مع امتدادات `pdo_mysql`, `mbstring`, `fileinfo`.
- **MySQL / MariaDB:** الإصدار 5.7 فما فوق أو MariaDB 10.x+.
- **Web Server:** Apache (مع تفعيل `mod_rewrite`) أو LiteSpeed أو Nginx.

---

## 🚀 طريقة التثبيت

1. ارفع الملفات إلى مجلد موقعك (مثلاً `public_html`).
2. قم بتعديل بيانات الاتصال بقاعدة البيانات في الملف `includes/config.php`:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'your_database_name');
   define('DB_USER', 'your_database_user');
   define('DB_PASS', 'your_database_password');
   define('SITE_URL', 'https://yourdomain.com');
   ```
3. افتح المتصفح وتوجه إلى رابط التثبيت:
   ```
   https://yourdomain.com/install.php
   ```
4. اضغط على **إنشاء الجداول** ثم قم بإنشاء حساب المدير.
5. **مهم:** احذف ملف `install.php` فور الانتهاء من التثبيت.
